`main.ts` (Node 22, stdlib only) writes one funny single-line excuse a developer gives when code breaks in production to `/output/entry.txt`:

> It wasn't my deploy — the cron job I wrote in 2023 just ran for the first time. It was waiting for February 29th.

The text is fixed and the program is fully deterministic: every run writes byte-identical output (113 characters, within the 1–200 gate).
